Contenedores HTML: div

Aprendé a agrupar y organizar elementos de una página web.

Ver explicación

¿Qué es la etiqueta div?

La etiqueta <div> significa división o sección. Es un contenedor que permite agrupar diferentes elementos HTML, como títulos, párrafos, imágenes y otros contenidos.

Por sí sola, la etiqueta div no modifica la apariencia de la página. Su utilidad es organizar el contenido y permitir aplicar estilos mediante CSS.

¿Para qué sirve?

  • Agrupar elementos relacionados.
  • Organizar el contenido de una página.
  • Aplicar estilos a varios elementos al mismo tiempo.
  • Crear secciones para el diseño web.

Ejemplo en HTML

<div class="ciudad">
  <h2>La Boca</h2>
  <p>Un barrio lleno de arte y color.</p>
  <img src="caminito.jpg">
</div>

Un ejemplo con CSS

.ciudad {
  background-color: lightblue;
  padding: 20px;
  border: 2px solid blue;
}

¿Qué tenemos que recordar?

  • Es un contenedor de elementos HTML.
  • Por defecto ocupa todo el ancho disponible.
  • Comienza en una nueva línea.
  • Podemos identificarlo mediante una clase o un ID.
🎯 Mini desafío

Creá tres contenedores div para presentar tres lugares de Buenos Aires. Cada uno debe tener un título, una descripción y una imagen.

Flexbox: organizar elementos

Descubrí cómo alinear, distribuir y ordenar elementos utilizando CSS.

Ver explicación

¿Qué es Flexbox?

Flexbox es una herramienta de CSS que permite organizar elementos dentro de un contenedor de manera flexible. Nos ayuda a alinearlos, distribuir el espacio disponible y cambiar su orden.

¿Cómo se activa?

Primero, seleccionamos el contenedor y escribimos:

.container {
  display: flex;
}

Propiedades principales

Propiedad ¿Para qué sirve?
display: flex Activa Flexbox.
flex-direction Define la dirección de los elementos.
flex-wrap Permite que los elementos pasen a otra línea.
justify-content Distribuye los elementos sobre el eje principal.
align-items Alinea los elementos sobre el eje transversal.
align-content Distribuye las líneas cuando hay varias filas o columnas.

Ejemplo 1: organizar en una fila

.container {
  display: flex;
  flex-direction: row-reverse;
  flex-wrap: wrap;
  justify-content: center;
}

Los elementos se organizan en una fila invertida, pueden pasar a otra línea y se ubican en el centro.

Ejemplo 2: organizar en una columna

.container {
  height: 300px;
  display: flex;
  flex-direction: column;
  flex-wrap: wrap;
  justify-content: space-evenly;
  align-content: center;
}

Cuando usamos flex-direction: column, el eje principal pasa a ser vertical. Por eso, justify-content controla la distribución vertical y align-items la alineación horizontal.

También podemos utilizar stretch para estirar los elementos y ocupar el espacio disponible cuando no tienen una altura definida.

🎯 Mini desafío

Creá una galería con cuatro imágenes. Utilizá Flexbox para organizarlas en una fila, centrarlas y permitir que pasen a otra línea cuando no haya espacio suficiente.
