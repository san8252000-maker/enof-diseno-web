DIV · Organizar el contenido

Aprendé a crear contenedores para agrupar elementos.

Ver tutorial

¿Para qué sirve?

La etiqueta <div> permite agrupar diferentes elementos de una página. Es como crear una caja para organizar textos, imágenes y otros contenidos.

¿Cómo se utiliza?

<div>
    <h2>Mi sección</h2>
    <p>Este es mi contenido.</p>
    <img src="imagen.jpg">
</div>

Todo lo que está dentro del DIV forma parte del mismo contenedor.

¡Probalo en tu web!

Creá un DIV que agrupe un título, un párrafo y una imagen sobre el tema de tu página.

🏷️

CLASS · Identificar elementos

Aplicá los mismos estilos a diferentes elementos.

Ver tutorial

¿Para qué sirve?

Una clase permite identificar uno o varios elementos HTML para darles un mismo estilo desde CSS.

¿Cómo se utiliza en HTML?

<h2 class="destacado">Mi título</h2>

<p class="destacado">
    Este texto también está destacado.
</p>

¿Cómo se aplica en CSS?

Para seleccionar una clase usamos un punto antes de su nombre: 

.destacado {
    color: #c9ff35;
    font-size: 24px;
    font-weight: bold;
}

¡Todos los elementos que tengan class="destacado" recibirán ese estilo!

¡Probalo en tu web!

Creá una clase llamada mi-estilo y aplicala a dos títulos o párrafos diferentes.

↔️

FLEXBOX · Acomodar elementos

Organizá contenidos en filas y columnas.

Ver tutorial

¿Para qué sirve?

Flexbox es una herramienta de CSS que permite organizar y alinear elementos dentro de un contenedor.

Primero, creamos un contenedor:

<div class="contenedor">
    <div>Elemento 1</div>
    <div>Elemento 2</div>
    <div>Elemento 3</div>
</div>

Después, usamos CSS:

.contenedor {
    display: flex;
    flex-direction: row;
    justify-content: center;
    align-items: center;
    gap: 20px;
}

display: flex activa Flexbox. flex-direction define la dirección. justify-content distribuye el espacio. align-items alinea los elementos. gap establece la separación.

¿Y si quiero una columna?

.contenedor {
    display: flex;
    flex-direction: column;
}
¡Probalo en tu web!

Organizá tres imágenes o tarjetas en una fila. Después probá cambiar la dirección a columna.

VIDEOS · Incorporar contenido multimedia

Agregá videos de YouTube a tu página.

Ver tutorial

¿Cómo incorporar un video?

  1. Abrí el video en YouTube.
  2. Hacé clic en Compartir.
  3. Elegí la opción Insertar.
  4. Copiá el código HTML que aparece.
  5. Pegalo dentro del BODY de tu página.

Ejemplo de código:

<iframe
    width="560"
    height="315"
    src="https://www.youtube.com/embed/ID_DEL_VIDEO"
    title="Mi video"
    allowfullscreen>
</iframe>

Reemplazá ID_DEL_VIDEO por el identificador del video que elegiste. También podés utilizar directamente el código que te proporciona YouTube.

¡Probalo en tu web!

Incorporá un video relacionado con el tema de tu página y comprobá que se pueda reproducir.

🔤

GOOGLE FONTS · Elegir tipografías

Personalizá los títulos y textos de tu página.

Ver tutorial

¿Para qué sirve?

Google Fonts ofrece tipografías gratuitas que podés incorporar a tu proyecto web.

¿Cómo se utiliza?

  1. Ingresá a Google Fonts.
  2. Buscá una tipografía que te guste.
  3. Seleccioná los estilos que quieras utilizar.
  4. Copiá el código de inserción que ofrece Google Fonts.
  5. Pegalo dentro de la etiqueta HEAD de tu HTML.

Ejemplo en HTML:

<link rel="preconnect"
href="https://fonts.googleapis.com">

<link href="https://fonts.googleapis.com/css2?family=Roboto&display=swap"
rel="stylesheet">

Aplicamos la tipografía en CSS:

h1 {
    font-family: "Roboto", sans-serif;
}

p {
    font-family: "Roboto", sans-serif;
}
¡Probalo en tu web!

Elegí una tipografía para los títulos y otra para los párrafos. Compará cómo cambia el diseño.

WEB LAB + GITHUB · Compartir tu web

Guardá tu proyecto y aprendé a publicarlo.

Ver tutorial

Parte 1 · Trabajar en Web Lab

Web Lab permite crear y editar los archivos HTML y CSS de tu proyecto.

  • Revisá que tu archivo principal sea index.html.
  • Organizá los archivos HTML, CSS e imágenes.
  • Guardá los cambios y comprobá la vista previa.
  • Utilizá las opciones de compartir del proyecto para mostrarlo.

Consultar la documentación de Web Lab

Parte 2 · Publicar con GitHub Pages

GitHub Pages permite publicar gratuitamente una página web a partir de los archivos de un repositorio.

  1. Creá una cuenta en GitHub.
  2. Creá un repositorio público para tu proyecto.
  3. Subí los archivos HTML, CSS e imágenes.
  4. Verificá que index.html esté en la carpeta principal.
  5. Entrá en Settings y luego en Pages.
  6. En Build and deployment, elegí Deploy from a branch.
  7. Seleccioná la rama main y la carpeta /(root).
  8. Guardá y esperá a que se publique el sitio.

Ver la guía oficial de GitHub Pages

Importante: los sitios publicados con GitHub Pages son públicos. No subas datos personales, contraseñas ni información privada.

¡Probalo en tu web!

Prepará tu proyecto para compartirlo. Revisá que todos los archivos estén incluidos y que los enlaces y las imágenes funcionen.
